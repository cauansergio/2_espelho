# Experimento: Associação de Dois Espelhos Planos

## 📋 Descrição do Experimento
Este experimento demonstra a formação de múltiplas imagens quando dois espelhos planos são associados em diferentes ângulos. É uma demonstração clássica de óptica geométrica que ilustra princípios fundamentais da reflexão da luz.

## 🎯 Objetivos
- Observar a formação de múltiplas imagens entre dois espelhos planos
- Compreender a relação entre o ângulo dos espelhos e o número de imagens formadas
- Verificar experimentalmente a equação N = (360°/θ) - 1
- Analisar os padrões de simetria nas imagens formadas

## 📊 Fundamentação Teórica

### Equação Fundamental
O número de imagens (N) formadas é dado por:

**N = (360°/θ) - 1**

Onde:
- N = número de imagens formadas
- θ = ângulo entre os espelhos (em graus)

### Princípio Físico
Cada imagem formada em um espelho serve como objeto para o outro espelho, criando um processo de reflexões sucessivas. Quando o ângulo entre os espelhos é um divisor exato de 360°, as imagens se distribuem simetricamente em um círculo.

## 📸 Exemplos Práticos

### Caso 1: Ângulo de 90°
- Imagens formadas: 3
- Disposição: As imagens formam um círculo completo com o objeto
- Aplicação: Canto de espelhos em elevadores

### Caso 2: Ângulo de 60°
- Imagens formadas: 5
- Disposição: Padrão hexagonal de imagens
- Aplicação: Caleidoscópios básicos

## 💡 Observações Importantes
1. Quanto menor o ângulo, mais imagens são formadas
